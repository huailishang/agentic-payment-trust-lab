# 外部参考资料导航

`docs/reference/` 只保存外部项目、协议、机构资料及其项目内提炼结论，不承载当前执行状态或主架构。

原则：**外部资料先分类、再批判吸收；只有映射到真实瓶颈并形成可验证切片后，才进入实现。**

## 身份与治理资料的跟踪优先级

后续涉及 Agent 问责、审计、交易治理时，按以下顺序看，不把所有外部材料放在同一权重：

```text
P0  GB/Z 185.9 智能体交易
P0  GB/Z 185.8 智能体审计
P1  MAS SAFR（金融运行时治理工程参考）
P1  GB/Z 242-2026 智能体技术要求
P2  GB/Z 185.1—185.7（身份 / 交互 / 工具基础）
P2  APASS / KYA 等真实产品基础设施（工程与产业落地信号，不替代标准）
P3  Sumsub 等企业调查（行业痛点与成熟度信号）
```

原则：**正式标准状态和金融运行时治理框架优先于厂商调查；外部材料只有击中真实瓶颈时才进入执行包。**

## 收录边界

外部项目进入这里，不代表：

- 已批准接入代码；
- 已成为项目依赖；
- 已升级成下一执行任务；
- 外部项目的对象或状态就是本项目标准。

只有满足下面链路，才允许从参考资料进入实现：

```text
真实项目瓶颈
→ 外部项目提供可验证机制
→ 冻结最小切片
→ 固定样品与指标
→ 本地验证
→ 独立复核
→ 再决定吸收 / 回滚 / 停止
```
