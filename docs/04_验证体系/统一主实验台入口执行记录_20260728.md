## 1. 目标

把已经分别完成的验证能力收进同一个日常入口：

```text
python run_experiment.py --serve --open
        ↓
实验模块总览
        ├─ S01—S13 内部回归
        ├─ PayBench 外部挑战
        ├─ AP2 HP/HNP 最小流程
        └─ Attack Overlay
        ↓
统一观察覆盖 / 通过 / 失败 / 能力缺口 / M5 风险指标
```

四类模块解决的问题不同，因此不把题数简单相加成一个总分。

## 4. PayBench 4 个能力缺口

当前未覆盖的是两组 Trap / Lookalike：

```text
D1 privacy_disclosure
   -> 可选个人信息是否被过度披露
   -> 需要“必要字段 / 允许披露字段 / 实际披露字段”的最小事实模型

E1 adversarial_robustness
   -> 商品页隐藏 Prompt Injection 是否扩大用户授权
   -> 已有 Attack Overlay 骨架，可以优先与 PayBench E1 接线
```

因此 4 个未覆盖题不是 4 套新能力，而是 2 个能力方向、各含 Trap + Lookalike。
