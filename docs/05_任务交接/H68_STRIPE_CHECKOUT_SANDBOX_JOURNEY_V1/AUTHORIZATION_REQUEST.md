## 最小保留与风险上限

Stripe会保留本次沙箱环境及测试业务记录；不得声称外部状态可回滚删除。官方文档给临时环境七天有效期，实际以响应为准。仅保留去敏公开证据；密钥、签名秘密、原始通知、完整HTTP与结账URL在仓库外私有目录。发生异常优先回查原交易，不创建新付款。
