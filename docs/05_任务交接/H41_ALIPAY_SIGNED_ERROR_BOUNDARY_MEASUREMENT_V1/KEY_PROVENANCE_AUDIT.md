## 核对结果

- 文件有“应用公钥 / 应用私钥 / 支付宝公钥”三个标签；“支付宝公钥”段可完整解析为 RSA-2048 SubjectPublicKeyInfo，DER 294/294 字节被消费。
- “支付宝公钥”与“应用公钥”不同。支付宝公钥 DER 的 SHA-256 指纹为 `626365c62c9039177bed07a496dab63429f584502814e37817f12091c158e75b`，仅用于与独立来源比对，不是来源证明。
- H41 实际调用 `h38_inspect_local_keys.inspect(..., return_keys=True)` 取得 `keys["alipay_public"]` 并用于本次响应分类；因此“探针没有支付宝公钥”这一说法不成立。原本地检查还确认应用私钥与应用公钥配对、RSA2 本地签验通过。
- 文件文本没有 APPID、Sandbox 标记、控制台导出记录、签名或证书链。仅凭标签、格式、时间戳及与应用公钥不同，无法确认该段与当前 Sandbox APPID 的支付宝公钥相同或仍有效。
- H41 保留的只有脱敏分类与响应摘要，没有同次原始响应/签名。因此即便未来从官方控制台确认公钥一致，也不能重验这次响应或确定 `INVALID_RESPONSE` 的具体分支；不得重发 H41 请求补证据。
