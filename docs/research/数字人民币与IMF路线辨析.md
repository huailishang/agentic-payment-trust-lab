# 数字人民币与IMF路线辨析

## 结论

数字人民币和IMF代币化框架值得共同研究，但当前证据不足以把“数字人民币2.0＝更复杂的sCBDC”写成事实。更稳妥的处理是把它拆成官方事实、研究框架和待证假设。

| 层级 | 当前可确认内容 | 项目处理 |
|---|---|---|
| 人民银行官方基线 | 数字人民币定位M0，是央行负债，实行中心化管理和双层运营；可加载不损害货币功能的智能合约 | 作为中国零售CBDC基线 |
| IMF研究框架 | Tokenized Finance讨论wCBDC、代币化存款、稳定币及受公共信用支持的安排，并强调结算资产、法律终局性、流动性和代码治理 | 作为比较框架，不替任何国家作制度分类 |
| 待证主张 | “数字人民币2.0”“数字存款货币”“CLT+分布式账本技术（DLT）双账本”“按机构属性形成广义/狭义银行双轨sCBDC”等 | 只有取得人民银行正式文件和清晰定义后才能升级为事实 |

## 对实验的实际影响

1. 将智能体（Agent）委托、商务订单、支付授权和结算资产拆开，不能把“可编程货币”当成解决全部授权问题的捷径。
2. 把卡、账户、数字人民币、代币化存款和稳定币作为可替换结算参数；第一阶段不接任何真实轨道。
3. 对实时/原子结算增加流动性、撤销、错误恢复和紧急中断测试，验证“减少摩擦也减少缓冲”的风险。
4. 智能合约只执行确定规则；概率性智能体负责提出行动，不能直接执行不可逆资金转移。
5. 研究结论必须标注来源级别，避免用相似架构强行推出同一法律属性。
