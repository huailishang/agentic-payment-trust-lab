# 外部参考资料导航

`docs/reference/` 只保存外部项目、协议、机构资料及其项目内提炼结论，不承载当前执行状态或主架构。

原则：**外部资料先分类、再批判吸收；只有映射到真实瓶颈并形成可验证切片后，才进入实现。**

## 收录边界

外部项目进入这里，不代表：

- 已批准接入代码；
- 已成为项目依赖；
- 已升级成下一执行任务；
- 外部项目的对象或状态就是本项目标准。

只有满足下面链路，才允许从参考资料进入实现：

```text
真实项目瓶颈
→ 外部项目提供可验证机制
→ 冻结最小切片
→ 固定样品与指标
→ 本地验证
→ 独立复核
→ 再决定吸收 / 回滚 / 停止
```
