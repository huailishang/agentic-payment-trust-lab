## 8. 日常阅读顺序

```text
想知道现在做到哪
    -> 01_项目现状/项目中控.md

想知道接下来干什么
    -> 02_未来规划/后续任务包.md

想知道为什么这样设计
    -> 03_架构设计/总体架构.md

想看具体业务或模块边界
    -> 03_架构设计/对应专项文档

想知道怎么验证没有回归
    -> 04_验证体系/样品驱动验证计划.md

想查研究或来源依据
    -> 研究材料（research）/ 参考资料（reference）
```

以后新增文档优先归入上述层级；不要重新把执行包、研究材料和长期架构文档堆回 `docs/` 顶层。
