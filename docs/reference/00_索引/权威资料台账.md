## 记录规则

- `事实`：来源直接明确表达。
- `推断`：由多个事实推出，必须写推理链和反例。
- `待证`：缺少正式来源或仅见二手解读，不进入架构结论。
- 企业资助研究、项目官网、链上统计和榜单分别记录资助方、数据截止日、清洗口径、标签方法、验证状态和利益关系。
- 每次引用记录访问日期和版本；协议升级后保留旧版本，不能覆盖历史实验依据。
